# 📢 Dynamic Notifications - Script

Sistema de notificações dinâmicas com suporte a TTS e respeito pelos horários de silêncio.

## 📋 Descrição

Script versátil para enviar notificações em português usando Text-to-Speech (TTS). Integra-se automaticamente com horários de silêncio configurados e suporta múltiplos canais de notificação.

## 🎯 Funcionalidades

- ✅ Notificações de voz em português
- ✅ Respeita horários de silêncio
- ✅ Suporte a múltiplos canais (Alexa, Notificações nativas, etc.)
- ✅ Priorização de mensagens
- ✅ Integração com input_boolean/input_select
- ✅ Histórico de notificações

## 🔧 Parâmetros

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `message` | texto | Mensagem a notificar |
| `channel` | select | Canal de notificação (alexa, notify, etc.) |
| `priority` | select | Nível de prioridade (low/normal/high) |
| `volume` | número | Nível de volume (0-100) |
