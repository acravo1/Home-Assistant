# 🎛️ Views - Dashboards Lovelace

Visões e painéis de controlo personalizados para o Home Assistant.

## 📋 Visões Disponíveis

### 🌊 **Sistema de Rega**
**Ficheiro:** `SistemaDeRega.yaml`  
**Descrição:** Dashboard completo para monitorização e controlo do sistema de rega inteligente.

**Componentes:**
- Status de todos os setores de rega
- Nível de humidade em tempo real
- Controles manuais para rega de emergência
- Histórico de operações
- Alertas e notificações

---

## 🚀 Como Usar

1. Copiar o ficheiro YAML desejado
2. No Home Assistant: **Settings > Dashboards > Create Dashboard**
3. Colar o conteúdo YAML
4. Ajustar IDs de entidades conforme necessário
5. Guardar e visualizar

---

## 📝 Convenção de Nomenclatura

- **Ficheiros YAML:** `PascalCase.yaml` (ex: `SistemaDeRega.yaml`)
- **Identificadores:** `snake_case` (ex: `system_rega_dashboard`)
